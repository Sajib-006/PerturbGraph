# PerturbGraph v1.0.0

First citable release of the Stable-Shift code associated with the ACM BCB 2026 paper “Stable-Shift: Predicting Transcriptional Responses of Unseen Gene Perturbations Using Graph Neural Networks with Biological Priors.”

## Included

- Stable-Shift benchmark implementations and classical/deep/GNN baselines.
- Replogle/K562 and Norman benchmark launch scripts.
- Perturb-seq preparation and qualitative-analysis utilities.
- Pinned pip/Conda environments.
- Canonical ACM citation and Zenodo-ready metadata.

Paper: https://doi.org/10.1145/3807503.3820871

Preprint: https://arxiv.org/abs/2606.24940
